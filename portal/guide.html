Save Files, Storage & Data Safety

How your campaigns, high scores, and worlds are protected in your browser
DATA INTEGRITY
⚠️
IMPORTANT: Avoid Incognito / Private Browsing Mode!
Browsers automatically wipe all IndexedDB databases, save states, and cookies when an Incognito window is closed. To ensure your GTA missions, Minecraft builds, and RetroX save states stay safe, always play in normal browser tabs!
🗄️ IndexedDB Storage

Games like GTA: Vice City, GTA III, Minecraft, and Diablo write their saves to your browser's high-speed local IndexedDB virtual file system (`IDBFS`).

🔄 Clearing Cache Safely

If you ever need to refresh game code, use Ctrl + F5. This refreshes the web assets without deleting your IndexedDB save files.

📦 Manual Backups

In Minecraft, click Export World. In RetroX, click the save state disk icon to download an offline copy of your save state directly.

Troubleshooting & Performance Tuning

Fix audio stuttering, low frame rates, or black screens in seconds
DIAGNOSTICS
🚀 Enable Hardware Acceleration

If 3D games (Vice City, GTA III, Mario 64) feel sluggish, make sure hardware graphics acceleration is turned on:

  • Chrome / Edge / Brave: Go to settings/system → Turn on "Use graphics acceleration when available" → Relaunch browser.
  • Firefox: Go to about:preferences → General → Performance → Check "Use recommended performance settings".
🔇 No Sound / Audio Not Playing?

Modern browsers block audio autoplay until the user interacts with the page.

🔊
Fix: Click anywhere on the game canvas. The browser will immediately resume the WebAudio context and audio will begin playing smoothly.
